## 账号权限

- 资料字段可由本人编辑；角色、停用状态及身份字段不开放直接写入。
- 停用状态在 Web principal、MCP PAT/OAuth 和 ESP32 凭证检查中即时读取。
  停用设备账号返回 403，保留配对凭证；账号恢复后可重新使用该设备。
- 停用同时撤销已有 MCP 凭证。数据库 restrictive policy 和公开的
  SECURITY DEFINER RPC 入口也检查当前账号状态，覆盖仍有效的旧 JWT。
- 受限题集元数据及复习取题都要求分享授权；匿名公开题集仍可阅读。
- admin 可以访问普通后台统计、用户读取和资料管理。角色授予、账号停用、删除、
  配额覆盖、系统设置、公告及标注队列操作保持 super_admin 权限。
  moderator 仅用于举报审核；其他后台页面在服务器端单独拒绝。

首次超级管理员由受控服务账号显式创建：

```sh
cd web
node --env-file=.env.local scripts/bootstrap-super-admin.mjs <已有且活跃的用户 UUID>
```

数据库会串行检查是否已经存在超级管理员；普通会话不能调用该 RPC。
该命令未对生产账号执行。本轮也没有应用生产迁移或修改线上角色。

## 待办提醒

每分钟的 cron 将到期且仍待办的任务写入本人提醒列表，时间变更使用新的幂等键。Web Push 在用户主动授权后启用，服务器需配置 VAPID_PUBLIC_KEY、VAPID_PRIVATE_KEY、VAPID_SUBJECT 和 CRON_SECRET；自托管需同样每分钟调用 /api/cron/todo-reminders。未配置密钥时仍投递到应用内提醒列表，并明确提示浏览器推送不可用。Android WebView 不支持 Web Push 时显示应用内渠道的使用边界。

投递使用数据库租约；临时错误按退避重试，失效订阅移除。发送前重新检查账号和任务状态，完成、取消或改期后取消尚未发送的旧通知。浏览器 notification tag 使用固定通知 ID，降低网络确认失败重试造成的重复。已被推送服务接受的消息无法撤回；服务接受与终端实际展示分别标识，未宣称真实设备验收。

新增提醒单测 8 项及数据库测试 12 项，针对本批和审核路由的 16 项单测通过，15 个 pgTAP 文件共 428 项通过。实际浏览器推送仍需要部署方密钥及终端授权，本轮没有发送生产通知。

## 账号导出与注销

个人资料新增账号数据入口。申请导出或注销要求五分钟内真实重新认证，刷新 JWT 的 iat 不作为依据。私有导出包含所有本人模块记录和本人存储文件，1000 行列表上限不影响导出；凭证和哈希排除。第三方资产保留引用，避免后台服务因用户填写任意路径而导出他人的私有文件。下载链接仅有效 60 秒，压缩包七天后清理。超过 512 MB 当前压缩包容量会明确失败，不发布部分导出。

注销立即停用并由租约任务清理，失败持续退避重试，不能把清理错误当成功。原账号文件被其他用户副本引用时，先保留副本文件再删除原文件；模块变更日志源记录先于 Auth 身份删除，以防删除触发器的外键冲突。管理员删除复用同一任务路径。每分钟 /api/cron/account-data 需在部署环境注册，Vercel 配置已登记。

真实本机 Supabase API、Storage 和 Auth 验证已通过：导出 1001 条待办、笔记及词条并解压校验原附件，注销后各模块和原账号文件清空，他人的题目及图片副本仍可读取。16 个 pgTAP 文件共 438 项通过。生命周期测试纳入 clean/upgrade CI；只使用新建的隔离测试账号，没有删除或导出真实用户。

## 历史 CRLF 函数体的迁移兼容

用户数据库在 `record_note_study_observation_v1` 报出 `Missing account guard insertion point`。原匹配要求 `begin` 后使用 LF，无法处理该历史函数保留的 CRLF。空库已撤销该 RPC 的 authenticated 授权，原 CI 没有覆盖旧库中仍开放该函数的情况。

修正只允许匹配处的可选 CR，保留账号守卫及找不到插入点时的失败行为。回归测试在事务内恢复真实历史 RPC 的 authenticated 授权和无守卫 CRLF 函数体，执行迁移中的实际守卫代码，同时验证 LF、带空白的 CRLF、SQL 函数、活跃账号返回值、停用账号拒绝、无用户 JWT 的服务调用，以及所有 definer 的签名、owner、ACL 和 search_path 保持一致；最后回滚测试夹具。

真实 PostgreSQL 中，旧代码已复现同一 RPC 的相同报错，新代码通过以上回归。完整数据库测试仍为 17 个文件、445 项通过，PostgREST 授权 smoke 与 Auth/Storage 导出注销集成也通过。回归纳入 clean/upgrade 数据库 CI；未对用户的远端数据库执行迁移。
