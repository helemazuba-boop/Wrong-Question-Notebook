## 账号权限

- 资料字段可由本人编辑；角色、停用状态及身份字段不开放直接写入。
- 停用状态在 Web principal、MCP PAT/OAuth 和 ESP32 凭证检查中即时读取。
  停用设备账号返回 403，保留配对凭证；账号恢复后可重新使用该设备。
- 停用同时撤销已有 MCP 凭证。数据库 restrictive policy 和公开的
  SECURITY DEFINER RPC 入口也检查当前账号状态，覆盖仍有效的旧 JWT。
- 受限题集元数据及复习取题都要求分享授权；匿名公开题集仍可阅读。
- admin 可以访问普通后台统计、用户读取和资料管理。角色授予、账号停用、删除、
  配额覆盖、系统设置、公告及标注队列操作保持 super_admin 权限。
  moderator 仅用于举报审核；其他后台页面在服务器端单独拒绝。

首次超级管理员由受控服务账号显式创建：

```sh
cd web
node --env-file=.env.local scripts/bootstrap-super-admin.mjs <已有且活跃的用户 UUID>
```

数据库会串行检查是否已经存在超级管理员；普通会话不能调用该 RPC。
该命令未对生产账号执行。本轮也没有应用生产迁移或修改线上角色。
