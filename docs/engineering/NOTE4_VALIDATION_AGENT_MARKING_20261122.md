验证线基线为 `0b0d2e7`，功能分支为 `feat/agent-marking-20261025`。

验证工作树已有一份未跟踪的 `20261025000000_agent_problem_marking.sql`。其内容与功能分支
基础迁移逐字节一致，随基础提交纳入验证线。合并数据库类型时保留 `opencode_agent_control_v1`
和 `oauth_poll_device_authorization`，并增加 `agent_mark_control_v1`。原始功能分支已含
本轮业务修复，验证线专属冲突修正仅涉及上述类型声明。

本轮固定 Registry `2d391ff`。App bundle、Registry 工作区 bundle 及 canonical registry 的
SHA-256 与 [语料锁](../../web/knowledge-registry.lock.json) 一致。

## 本地验证

- Web Vitest 通过 208 个文件、2,306 项测试。5 个文件和 12 项测试条件跳过。
- Worker 11 项通过。i18n 的中英文各 2,585 个键，格式和语料锁校验通过。
- 使用 CI 占位配置完成 Webpack 生产构建、TypeScript 检查、115 页静态生成和客户端凭据扫描。
- 从本地数据库复制 schema 到独立测试库，回放验证线的 8 条额外迁移及截止时间迁移。
  36 项 Agent SQL 断言和 8 项原有分类租约断言通过。数据库版本验证范围为本轮回放和相关 SQL 路径。
- 在同一隔离库单独执行全量 Vitest 中默认跳过的 MCP 回执联调。等待十分钟的合成题获得完整
  五分钟预算，提交后可查询并重放接受回执。隔离库已清理。

数据库是否应用迁移、OpenCode 实际默认模型和真实题目分类质量需在部署验收中单独核对。
远端 CI、部署、生产数据库和设备 HIL 状态不由本地检查点覆盖。
